# 🐍 Python Programming — Module 1 Capstone Project

## 📌 Project Overview

This repository contains my **Module-1 Capstone Project: Introduction to Computer Programming**, completed as part of my Python learning journey.

The project is designed to build a strong foundation in Python programming through a collection of practical, problem-solving exercises. It covers concepts ranging from basic variables and data types to **functions, advanced looping techniques, Object-Oriented Programming (OOP), and exception handling**.

The exercises use real-world scenarios such as score calculation, nutrition analysis, sales data, stock filtering, banking systems, calculators, games, and data processing.

---

## 🎯 Objectives

* Build a strong foundation in Python programming.
* Understand Python syntax, variables, and data types.
* Practice operators, indexing, slicing, and built-in methods.
* Develop problem-solving skills using conditional statements and loops.
* Create reusable programs using custom functions.
* Apply lambda functions, comprehensions, and functional programming concepts.
* Understand and implement Object-Oriented Programming.
* Handle invalid inputs and runtime errors using exception handling.
* Apply Python concepts to practical, real-world scenarios.
